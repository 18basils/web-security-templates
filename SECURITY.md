## Reporting a Vulnerability

We take the security of our web headers, scripts, and CI/CD blueprints seriously. If you discover a security flaw, misconfiguration, or bypass in any template in this repository, please disclose it responsibly.

### How to Report
1. **GitHub Private Vulnerability Reporting (Preferred)**:
   - Navigate to the **[Security > Advisories](https://github.com/18basils/web-security-templates/security/advisories/new)** tab on GitHub and click **"Report a vulnerability"**.
   - This opens a private thread directly with the maintainer (`@18basils`) without exposing the issue publicly.
2. **Direct Contact**:
   - Contact the maintainer via GitHub profile: [@18basils](https://github.com/18basils).

### What to Include
* Affected template file path(s).
* Description of the security weakness or header bypass and its potential impact.
* Steps to reproduce or scanner verification output.

### Response Timeline & Recognition
* **Initial Acknowledgement**: Within 48 hours.
* **Triage & Patch Release**: Within 5 business days.
* **Recognition**: Validated reports are credited in our security advisories and the `README.md` Hall of Fame.
