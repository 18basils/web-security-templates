Install on Your Platform

Select your operating system to view setup instructions

Windows 10 / 11 Setup

Runs as a standalone portable app or full user-space installer.

# Install via PowerShell or download Setup.exe
winget install 18basils.DesktopCompanion

Apple macOS Setup (Apple Silicon & Intel)

Integrates directly into your Mac Menu Bar with floating desktop pet overlay.

# Mount the DMG and copy to Applications
open Apple-Companion-macOS.dmg
cp -R "/Volumes/Apple Companion/Apple Companion.app" /Applications/

Linux AppImage Setup

Zero-install single binary compatible with Ubuntu, Fedora, and Arch.

chmod +x DesktopCompanion-x86_64.AppImage
./DesktopCompanion-x86_64.AppImage

Android & iOS Mobile Installation

Point your phone camera at the screen QR code or install direct APK/TestFlight builds.

# Android direct install
adb install Phone.Companion.apk
